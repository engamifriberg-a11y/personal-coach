האפליקציה עצמה עוד לא מחוברת לכתובת הזו

⚠
האתר כאן חי; האפליקציה לא. האפליקציה צריכה שרת שרץ באופן קבוע ומסד נתונים שנשמר בין בקשות - חשבונות, תוכניות ואימונים. אירוח סטטי מגיש קבצים בלבד, ולכן האפליקציה אינה זמינה מכאן. זו הצהרת מצב, לא תקלה.

מה כן אפשר לעשות עכשיו

להריץ מקומית

הקוד שלם ועובד. על מחשב עם Node 22:

npm run migrate
npm start

ואז האתר ב-localhost:3000 והאפליקציה ב-/app. אין תלויות להתקין.

לראות את הממשק

תצוגה של מסכי האפליקציה - בית, לוח שבועי, אימון פעיל, ספרייה, תזונה ומעקב - שהופקה מקוד הממשק האמיתי.

תצוגה סטטית: הכפתורים והטפסים אינם פעילים בה.

איך מחברים את האפליקציה לאוויר

שני מסלולים, ושניהם אמיתיים:

שרת שרץ קבוע + דיסק

Railway, Render, Fly.io או מכונה וירטואלית. הקוד עולה כמו שהוא, בלי שינוי: אותו תהליך Node, אותו קובץ SQLite על דיסק מתמיד. זה המסלול הקצר, והוא מתאים למוצר בשלב הזה.

אירוח ללא שרת + מסד נתונים מנוהל

פונקציות ללא שרת דורשות מסד חיצוני במקום הקובץ המקומי - למשל Postgres מנוהל. שכבת הגישה לנתונים בפרויקט מרוכזת בקובץ אחד, ולכן ההחלפה אפשרית, אבל היא כתיבה מחדש של אותה שכבה ובדיקה שלה מול המסד החדש.

ℹ
בכל אחד מהמסלולים, ברגע שהאפליקציה עולה לכתובת, הדף הזה מוחלף בה והקישורים באתר מתחילים לעבוד. גם ההתקנה על הטלפון תתחיל לעבוד - היא דורשת HTTPS ושרת חי.
